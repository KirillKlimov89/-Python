ДЕФЕКТ №1
Название: методы класса StringUtils не обрабатывают None
Файл: string_utils.py
Методы: capitalize, trim, contains, delete_symbol
Шаги воспроизведения:
    1. Создать объект StringUtils.
    2. Вызвать любой из методов, передав первым аргументом None.
Ожидаемый результат: метод корректно реагирует на None —
    возвращает None или пустую строку без исключения.
Фактический результат: AttributeError: 'NoneType' object has no
    attribute 'capitalize' (и аналогично у остальных методов).
Критичность: средняя
Влияние: утилита падает при неожиданных входных данных.
    Вызывающий код может получить необработанное исключение.


ДЕФЕКТ №2
Название: метод contains не обрабатывает нестроковый symbol
Файл: string_utils.py
Метод: contains
Шаги воспроизведения:
    1. Создать объект StringUtils.
    2. Вызвать contains("SkyPro", None).
Ожидаемый результат: возвращает False или бросает понятное
    исключение (ValueError / TypeError с осмысленным текстом).
Фактический результат: TypeError: argument should be a str or an
    object with __index__ method. Исключение не перехватывается,
    потому что блок try/except ловит только ValueError.
Критичность: средняя
Влияние: TypeError вместо ожидаемого False. Поведение не
    соответствует документации метода.


ДЕФЕКТ №3
Название: метод trim не определяет поведение для строки из пробелов
Файл: string_utils.py
Метод: trim
Шаги воспроизведения:
    1. Создать объект StringUtils.
    2. Вызвать trim("   ") (строка только из пробелов).
Ожидаемый результат: поведение не описано в документации;
    требуется либо вернуть пустую строку, либо сохранить её
    как есть.
Фактический результат: возвращает пустую строку "".
Критичность: низкая
Влияние: пользователь метода не знает заранее, что получит
    на входе из одних пробелов. Поведение не задокументировано.
